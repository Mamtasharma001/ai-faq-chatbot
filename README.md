# AI FAQ Chatbot

An intelligent FAQ chatbot that delivers instant, conversational answers to user queries. Instead of manually searching through documentation or scrolling through long FAQ pages, users can simply ask a question in natural language and receive relevant responses in real time.

The project is designed to provide a clean, responsive interface with a fast chat experience, making it suitable for businesses, educational platforms, customer support systems, and personal knowledge bases.

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/ai-faq-chatbot.git
```

Navigate to the project directory:

```bash
cd ai-faq-chatbot
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## How It Works

1. The user enters a question in the chat interface.
2. The chatbot processes the input.
3. The AI generates a relevant response.
4. The response is displayed instantly in the conversation window.
5. The chat continues naturally, allowing users to ask follow-up questions.
